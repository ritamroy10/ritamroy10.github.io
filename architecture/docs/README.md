# Documentation map

The documentation is grouped by the task it supports:

| Document | Use it for |
|---|---|
| `architecture_workflow.html` | Self-contained visual overview of the request lifecycle |
| `harness.md` | Seven-layer harness contract and lifecycle |
| `model_endpoints.md` | OpenAI-compatible endpoint and model-slot contract |
| `mac_runbook.md` | Mac development and remote-endpoint setup |
| `windows_runbook.md` | Windows/Ollama live testing |
| `runpod_runbook.md` | RunPod deployment and preflight |
| `quantization_guide.md` | Quantization, memory, and deployment profiles |

The root-level `architecture_workflow.html` is retained as a compatibility
copy. New links should target this directory's canonical visual.
